# Roadmap

## Current foundation

**Being qualified:**
- repository identity and legal texts;
- architecture and governance;
- native documentation;
- dedicated validation tools.

**Domain capabilities and claims:** empty.

## Capability milestones

1. **The ten v1 record schemas with golden fixtures,** starting with the common envelope (`circuit_core.envelope.v1`) and the nine contract schemas, each enrolling strict typing, native documentation and meaningful coverage in the same change.
2. **Deterministic canonical digesting and entity-reference resolution,** refusing ambient paths, symlinks and unpinned cross-repository references.
3. **Operation-profile and licence-isolation admission checks,** enforcing separate-process boundaries for copyleft tools, pinned container/Nix digests, two-stage cancellation and mandatory no-model paths.
4. **Data-compartment, enclave-policy and person-approval validators,** enforcing signed-frame role requirements, in-enclave release prerequisites and application custody of approval evidence summaries.
5. **Provider-manifest registration checks** for downstream circuit repositories without importing their domain code.

**Enrolled with every implementation change:**
- strict native typing and linting;
- native documentation;
- meaningful statement and branch coverage;
- affected boundary tests and benchmarks.

**Requires its own evidence and explicit approval:**
- remote licence-server exceptions inside confidential enclaves;
- downward data-classification releases;
- post-pilot approval-audit activation;
- public activation and release.

No availability date is promised. No performance, yield or productivity gain is promised either.
