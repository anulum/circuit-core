# Circuit Core

Circuit Core is being built as the domain-free contract, admission, data-handling and approval kernel imported by every other circuit platform repository. It defines how entities, design views, operation profiles, execution requests, admission decisions, data compartments, autonomy envelopes, person-in-role approvals and hierarchical chip budgets are represented and checked. Its current executable surface is repository validation tooling. It has no installed contract-kernel package, admission runner, approval verifier or qualified record schema.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
